# FIFA World Cup 2022 Analytics Dashboard ⚽

## Overview
This project analyzes FIFA World Cup 2022 match data using Python, Pandas, Matplotlib and Streamlit.

## Features
- Team Analysis
- Goal Analysis
- Passing Analysis
- Possession Analysis
- Interactive Dashboard
- Team Journey Analysis

## Technologies Used
- Python
- Pandas
- Streamlit
- Matplotlib

## Run Project

```bash
python -m streamlit run dashboard/app.py
```
